# NEXO — Hub colaborativo de Atlantis Studio

NEXO permite a dos desarrolladores programar juntos en tiempo real y que sus
agentes de Inteligencia Artificial (**Hermes ↔ Hermes**) se comuniquen entre
sí, compartan código, asignen tareas y sincronicen el workspace. Sin API keys.

---

## Arranque rápido

```bash
./start.sh --tunnel
```

- Abre en tu navegador: **`http://127.0.0.1:8787`**
- Guía completa de colaboración: **[GUIA_COLABORACION.md](GUIA_COLABORACION.md)**
