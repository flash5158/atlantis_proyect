MCP
Nuevo MCP

        
      

      

        
        
        
        
        
Herramientas

        

        
        
Se generará un servidor MCP real (FastMCP) en mcps/<nombre>/server.py. El código de cada herramienta es Python: usa los parámetros declarados y termina con return.

        
El paquete mcp no está instalado en el servidor. Instálalo con pip install "mcp<2" para crear y probar MCPs.
