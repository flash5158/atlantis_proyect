FAQ

Preguntas frecuentes

Respuestas directas, sin letra pequeña.

¿Necesito internet para usarlo? +
No para programar. Solo necesitas conexión cuando tu compañero está fuera de tu red local — ahí se usa un túnel seguro punto a punto. En tu misma red, todo funciona sin internet.
¿Mis datos salen de mi máquina? +
No. Tu código, tus chats y tus modelos viven en tu red. No hay nube de por medio, no se crean cuentas externas y no se necesita ninguna API key.
¿Qué asistentes de IA puedo conectar? +
Hermes, Claude Code, Ollama o cualquier asistente con línea de comandos. Puedes tener varios conectados a la vez, cada uno con su identidad, y cambiar entre ellos con un clic.
¿Cuánto cuesta? +
Nada. No hay planes, suscripciones ni funciones bloqueadas por pago.
¿En qué sistemas funciona? +
Windows, macOS y Linux. El paquete es portable: lo llevas a otra computadora y sigue funcionando.
¿Qué es un servidor MCP y para qué sirve el MCP Builder? +
MCP (Model Context Protocol) es la forma estándar de darle herramientas a un asistente de IA. El MCP Builder te guía paso a paso para crear tu propio servidor con tus herramientas, probarlo en vivo y usarlo desde tus agentes.
